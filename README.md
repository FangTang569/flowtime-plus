# amble / flowtime+

一个极简的心流时间法（Flowtime Technique）计时器。

> flowtime+ 是 amble 的改版：去掉时间块视图与快捷补录，不再关心「总时长」，
> 只保留「工作 → 休息」的比例循环，并新增「未使用休息」池。
> 它使用**独立的数据库文件**（`flowtime-plus.db` / 开发期 `flowtime-plus-dev.db`），
> 不会读写原版 amble 的数据。

> 目前还处于早期开发阶段

## 构建

```bash
# 安装依赖
npm install

# 开发模式
npm run tauri dev

# 打包（产物在 src-tauri/target/release/bundle/）
npm run tauri build

# 计时器语义自测（纯 node，无 DOM/Tauri，覆盖休息池与比例锁定）
npm run selftest
```


## 功能

- **正计时工作模式**：开始即进入专注，不设倒计时，也没有「总时长」的概念
- **只显示休息**：读数区是两个并列账户 —— 左栏 `EARNED`（本轮已赚到的休息 = 已过时间 × 比例）、右栏 `UNUSED`（未使用休息池）。任何时候都不显示工作时间
- **比例锁定**：休息比例只能在开始前设定，一旦开始就固定下来
- **未使用休息池**：休息提前结束时，没用完的休息会存起来，下次休息时自动接着用
- **统计（Stats）**：周/月/年维度的休息占比、柱状图，支持 ← → 翻页
- **画中画悬浮窗**：最小化后也能随时看到计时状态
- **数据本地存储**：SQLite 持久化 + 每日自动备份（保留 7 天）

## 使用方法

### 计时

| 操作 | 按钮 | 说明 |
|------|------|------|
| 开始专注 | 「▶ Start」 | 开始正计时，左栏 `EARNED` 开始累积「已赚到的休息」 |
| 暂停 | 「⏸ Pause」 | 结算本次赚到的休息，等待你决定休息还是继续 |
| 继续专注 | 「▶ Resume」 | 从暂停处继续累计工作时长（与 Start Rest 各占半宽） |
| 开始休息 | 「☾ Start Rest」 | 先倒计时赚到的休息，用完再自动接上未使用休息池 |
| 结束休息 | 「■ End Rest」 | 休息中唯一的主按钮；剩余休息自动进池 |
| 结束会话 | End Session | 小号文字链接，只在工作中/暂停时出现；结束整个循环 |

### 休息比例

- 默认 20%（专注 5 分钟 → 休息 1 分钟）
- 显示格式如 `20% ≈ (work 5:1)`，约等号表示比例取整后的近似值
- **只在待机（未开始）时可调**，主界面与设置页的滑块都会锁定并显示 `locked`
- 主界面的滑块放在面板最下方 —— 它只在开始前有用，所以不夹在读数区和播放键之间
- 拖动时滑块上方会浮出精确百分比；**滚轮和 ←/→ 方向键每次各调 1%**
- 刻度按真实比例摆放（5 / 25 / 50 / 75 / 100），滑块可拖动区域是 28px 高而不是一条细线

### 未使用休息

提前结束休息时，剩余休息时长会累加到「未使用休息」池里，显示在读数区右栏 `UNUSED`。

> 读数区规则：哪个账户在动，哪个就是实心深色；不参与当前动作的那栏淡出。所以两段式休息看得出交接 —— 左栏倒数到 `00:00` 变淡，右栏转琥珀接着倒数。

- **获得**：休息过程中点 End Session，剩余时长进池
- **清零**：每天本地零点自动清零，跨日不会累积
- **使用**：常规休息只倒计时「赚到的休息」，用完**之后**才会自动接着消耗池里的时间
- **上限**：每次休息开始时会把当时的池余额快照下来，本次最多只能休息「赚到的 + 快照余额」，所以不存在无限休息

### 统计

- 顶部滑块切到柱状图图标
- Week / Month / Year 切换粒度
- 顶部 ← → 翻看历史周期
- 柱状图高度随数据量自适应

### 悬浮窗

- 窗口右上角画中画图标开关
- 悬浮窗置顶显示当前计时，可拖拽，悬停出现关闭按钮
- 休息中数字为绿色，消耗未使用休息池时为琥珀色；待机时悬浮窗显示的是池余额

### 设置

- 顶部滑块切到齿轮图标
- 可设置默认休息比例，自动保存，下次启动生效；与主界面滑块联动，休息循环进行中同样锁定



### 前置要求

- Node.js ≥ 18
- Rust ≥ 1.77
- Windows 需要 Visual C++ Build Tools 与 WebView2

### iOS 自用构建

iOS 构建需要 macOS，Windows 用户可通过 GitHub Actions 云端构建：

1. 仓库 Actions 页面 → **Build iOS (unsigned IPA)** → Run workflow
2. 构建完成后下载 artifact（未签名 IPA）
3. 用 [Sideloadly](https://sideloadly.io/) 登录 Apple ID 签名并安装到 iPhone（免费账号 7 天过期，需每周重签）
